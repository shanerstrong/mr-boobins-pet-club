# Visual-design review profile

Freeze the design source of truth, target viewports, states, and acceptance rubric before editing.

For each pass:

1. Render or capture the real implementation.
2. Compare hierarchy, layout, spacing, typography, color, imagery, responsive behavior, interaction states, and accessibility.
3. Record concrete discrepancies with locations and measurable corrections.
4. Fix the highest-impact batch with one writer.
5. Render again rather than judging from code alone.

Stop when required views pass, remaining differences are accepted, or the bounded loop reaches its limit.
