# Docs and media review profile

Protect originals and preserve provenance.

Review:

1. Content completeness and source fidelity.
2. Original-to-derivative traceability.
3. Metadata, filenames, catalog records, and approval state.
4. Layout, pagination, clipping, image quality, captions, and accessibility.
5. Export format, dimensions, links, and final-file integrity.

Render documents, PDFs, slides, or media outputs for visual inspection. Never approve an artifact from source text alone when layout matters.
