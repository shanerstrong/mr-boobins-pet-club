# Visual-design profile

## Source of truth

Record the authoritative design file, reference images, tokens, viewports, interaction states, and responsive rules.

## Visual QA loop

1. Run the real implementation.
2. Capture required views and states.
3. Compare hierarchy, spacing, typography, color, imagery, responsiveness, interaction, and accessibility.
4. Record measurable discrepancies.
5. Fix with one writer and render again.

Use the bounded review limits in `AGENTS.md`.
