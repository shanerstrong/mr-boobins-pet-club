# Software profile

## Required planning

- Map entry points, runtime boundaries, data flow, external dependencies, and compatibility constraints.
- Record exact lint, type-check, test, build, migration, accessibility, security, and smoke-test commands that actually exist.

## Review priorities

Correctness, security, data loss, regressions, compatibility, missing tests, and failed deterministic gates outrank style preferences.

## Completion

Do not claim success when a required check is skipped or failing. Explain unavailable checks and remaining risk.
