## Implementation notes

- Figma exports no authored motion timelines for the composed screens. Runtime animation therefore follows the documented product timing and state transitions with React Native `Animated`, while reduced-motion keeps state meaning and removes decorative movement.
- No expiring Figma image asset is used. Jack, the room, controls, hygiene effects, and audio are original local/code-native assets.
- Keep the message slot at 52px and control coordinates stable across room states.
- Do not publish the Figma library or create Code Connect mappings until separately authorized.
